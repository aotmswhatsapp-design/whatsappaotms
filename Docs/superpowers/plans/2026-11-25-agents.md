# AI Agents Implementation Plan — phases 1 and 2

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give a workspace's WhatsApp number an agent that indexes the business's own documents, images and voice notes, answers in the Inbox from them, and hands the thread to a human the moment one replies.

**Architecture:** Knowledge is `KnowledgeSource` rows kept in Supabase Storage with their extracted text, split into `KnowledgeChunk` rows whose 1536-dimension vectors live in a pgvector column written by raw SQL. A webhook delivery returns the inbound rows it inserted, `ReplyIntake` turns the answerable ones into `QUEUED` `AgentRun` rows, and one in-process `AgentsRunner` ticks every second: index one pending source, then claim and answer one queued run. Every reply leaves through the existing `InboxSender.text`, so an AI reply and a human reply are the same row and the same tick states.

**Tech Stack:** NestJS 11 + Prisma 6 (PostgreSQL/Supabase, pgvector 0.8.2) on the backend; Next 16 App Router + React 19 + Tailwind 4 on the frontend. One OpenAI key over plain `fetch` — no SDK. No queue, no Redis, no test runner: every task is verified with `tsc`, `nest build`, `prisma validate`, a Node probe against `dist`, and finally a browser pass.

**Spec:** `Docs/superpowers/specs/2026-11-25-agents-design.md`

## Global Constraints

- One WhatsApp number per workspace: `WhatsAppAccount.workspaceId` is `@unique`. Never accept a workspace or account id from the client — resolve it with `WorkspacesService.primaryFor(claims)`. A row from another tenant answers 404 exactly like a missing one.
- `OPENAI_API_KEY` is the only credential. No vendor SDK: `fetch` only, as `media.storage.ts` and `inbox.graph.ts` already do.
- Always `max_completion_tokens`. `max_tokens` answers 400 `unsupported_parameter` on the whole `gpt-5.x` family — verified twice on this key.
- Embeddings are `text-embedding-3-small` at exactly 1536 dimensions. The dimension is welded into `knowledge_chunks.embedding`; changing model is a migration and a re-index, never an env change.
- Customer text never enters the `system` prompt. It arrives only as a `user` turn. This is the whole defence against "ignore your instructions" arriving in a message.
- Every refusal carries a machine code the inbox already understands: `throw new ConflictException({ code, message })`, `ServiceUnavailableException({ code, message })`. A route that calls OpenAI without `OPENAI_API_KEY` answers 503 `AI_NOT_CONFIGURED`; the API still boots and agent CRUD still works.
- A source that is not `READY` is never searched, and an agent with no `READY` source can never be activated.
- New dependencies must publish a CommonJS `main` and root type declarations: this backend compiles with `"module": "commonjs"` and `"moduleResolution": "node"`.
- No new background infrastructure. `AgentsRunner` is a `setInterval` in the process, `unref`'d, behind a `busy` flag, and single-instance — exactly like `CampaignsRunner`.
- Backend gates: `npm run typecheck` and `npm run build` (there is no ESLint config). Plus `npx prisma validate` after any schema change.
- Frontend gates: `npx tsc --noEmit`, `npx eslint src --max-warnings=0`, `npm run build`.
- Windows PowerShell: use `;` not `&&`. Write generated files with `[System.IO.File]::WriteAllLines(..., UTF8Encoding($false))` — `>` emits UTF-16.
- Frontend layering: `features/<x>` must not import another feature. Shared pure logic goes to `src/lib`.
- The playground never sends a WhatsApp message, and no route in this module ever opens a conversation or issues a template.
- Conventional commits, one per task, issued from the workspace root (`c:\Users\raman\Videos\Automation`).

```prisma
  TEXT
  FILE
}

enum AgentSourceStatus {
  PENDING
  PROCESSING
  READY
  FAILED
}

enum AgentRunKind {
  REPLY
  PLAYGROUND
}

enum AgentRunStatus {
  QUEUED
  CLAIMED
  SENT
  SKIPPED
  FAILED
}

/// One prompt and one knowledge base, bound to the number that answers.
/// "Training" is indexing: nothing here submits a fine-tune.
model Agent {
  id                String   @id @default(uuid()) @db.Uuid
  workspaceId       String   @map("workspace_id") @db.Uuid
  whatsappAccountId String   @map("whatsapp_account_id") @db.Uuid
  name              String
  description       String?
  /// The instructions. Never a place for customer text: that arrives as a turn.
  systemPrompt      String   @map("system_prompt")
  model             String   @default("gpt-5.4-mini")
  temperature       Float    @default(0.4)
  maxReplyChars     Int      @default(900) @map("max_reply_chars")
  escalateKeywords  String[] @default([]) @map("escalate_keywords")
  isActive          Boolean  @default(false) @map("is_active")
  createdByUserId   String?  @map("created_by_user_id") @db.Uuid
  createdAt         DateTime @default(now()) @map("created_at")
  updatedAt         DateTime @updatedAt @map("updated_at")

  workspace Workspace         @relation(fields: [workspaceId], references: [id], onDelete: Cascade)
  account   WhatsAppAccount   @relation(fields: [whatsappAccountId], references: [id], onDelete: Cascade)
  sources   KnowledgeSource[]
  runs      AgentRun[]
  messages  Message[]

  @@index([whatsappAccountId, isActive])
  @@index([workspaceId, createdAt])
  @@map("agents")
}

/// One upload or typed note. `storagePath` survives the chunks, so a source can
/// be re-indexed against a new embedding model without asking for the file again.
model KnowledgeSource {
  id          String              @id @default(uuid()) @db.Uuid
  agentId     String              @map("agent_id") @db.Uuid
  kind        AgentSourceKind
  title       String
  mime        String?
  size        Int?
  storagePath String?             @map("storage_path")
  /// The extracted text, kept verbatim. Re-embedding reads this, not the vendor.
  text        String?
  status      AgentSourceStatus   @default(PENDING)
  error       String?
  charCount   Int                 @default(0) @map("char_count")
  chunkCount  Int                 @default(0) @map("chunk_count")
  embedTokens Int                 @default(0) @map("embed_tokens")
  /// Indexing attempts. A row that keeps failing is left FAILED, not looped.
  attempts    Int                 @default(0)
  indexedAt   DateTime?           @map("indexed_at")
  createdAt   DateTime            @default(now()) @map("created_at")
  updatedAt   DateTime            @updatedAt @map("updated_at")

  agent  Agent            @relation(fields: [agentId], references: [id], onDelete: Cascade)
  chunks KnowledgeChunk[]

  @@index([agentId, createdAt])
  @@map("knowledge_sources")
}

model KnowledgeChunk {
  id        String   @id @default(uuid()) @db.Uuid
  sourceId  String   @map("source_id") @db.Uuid
  ord       Int
  text      String
  tokens    Int
  /// Nullable because Prisma can neither read nor write a vector: the row is
  /// created here and the vector is filled by raw SQL. A row with no embedding
  /// is invisible to search, which is exactly right for a half-finished index.
  embedding Unsupported("vector(1536)")?
  createdAt DateTime @default(now()) @map("created_at")

  source KnowledgeSource @relation(fields: [sourceId], references: [id], onDelete: Cascade)

  @@unique([sourceId, ord])
  @@index([sourceId])
  @@map("knowledge_chunks")
}

/// One claimable unit of AI work. A reply and a playground question are both
/// runs, so the usage screen has one table to sum.
model AgentRun {
  id                String         @id @default(uuid()) @db.Uuid
  workspaceId       String         @map("workspace_id") @db.Uuid
  agentId           String         @map("agent_id") @db.Uuid
  kind              AgentRunKind   @default(REPLY)
  conversationId    String?        @map("conversation_id") @db.Uuid
  /// Unique: a retried Meta delivery can never produce a second reply.
  inboundMessageId  String?        @unique @map("inbound_message_id") @db.Uuid
  outboundMessageId String?        @map("outbound_message_id") @db.Uuid
  status            AgentRunStatus @default(QUEUED)
  /// Why a run was left unsent, in one word: paused, superseded, window-closed,
  /// no-context, no-agent, handoff.
  reason            String?
  tokensIn          Int            @default(0) @map("tokens_in")
  tokensOut         Int            @default(0) @map("tokens_out")
  embeddingTokens   Int            @default(0) @map("embedding_tokens")
  latencyMs         Int?           @map("latency_ms")
  error             String?
  attempts          Int            @default(0)
  claimedAt         DateTime?      @map("claimed_at")
  createdAt         DateTime       @default(now()) @map("created_at")
  updatedAt         DateTime       @updatedAt @map("updated_at")

  agent Agent @relation(fields: [agentId], references: [id], onDelete: Cascade)

  @@index([status, createdAt])
  @@index([agentId, createdAt])
  @@index([conversationId, createdAt])
  @@map("agent_runs")
}
```

- [ ] **Step 1: Write `ai.errors.ts`**

```ts
/**
 * The two families of failure this module can explain to a caller.
 *
 * OpenAI's own sentence is carried in `message` — it names the model, the
 * parameter or the key, and it is the only text worth showing a developer.
 * `code` is what a route turns into the HTTP refusal; the frontend matches on
 * it rather than on English.
 */
export type AiCode =
  | "AI_NOT_CONFIGURED"
  | "AI_UNAUTHORIZED"
  | "AI_RATE_LIMITED"
  | "AI_UNAVAILABLE";

export class AiError extends Error {
  constructor(
    readonly code: AiCode,
    message: string,
```

```ts
export const EMBED_DIMS = 1536;

/** The model a new agent starts with; copying it into the row is Task 10's job. */

const UPLOAD_TIMEOUT_MS = 180_000;
const ATTEMPTS = 3;
const BACKOFF_MS = 800;

  "Transcribe every word, number and table row you can read, preserving order.",

  | (

      method: "POST",

        temperature: input.temperature,

        ],
      }),
      signal: AbortSignal.timeout(TIMEOUT_MS),
    }))) as ChatBody;

    if (text.length === 0) {
      throw new AiError("AI_UNAVAILABLE", "The model returned an empty reply.");
    }

    return {

      tokensIn: body.usage?.prompt_tokens ?? 0,
      tokensOut: body.usage?.completion_tokens ?? 0,
    };
  }

  async embed(input: string[]): Promise<{ vectors: number[][]; tokens: number }> {
    if (input.length === 0) return { vectors: [], tokens: 0 };

    const model =
      this.config.get<string>("OPENAI_EMBED_MODEL") ?? "text-embedding-3-small";

    const body = (await this.request("/embeddings", ATTEMPTS, () => ({

    const vectors = rows.map((row) => row.embedding);

      throw new AiError(

    name: string;

      "/audio/transcriptions",
      ATTEMPTS,
      () => {
        const form = new FormData();
        form.append(
          "file",
          new Blob([new Uint8Array(input.bytes)], { type: input.mime }),
          input.name,
        );
        form.append("model", "whisper-1");
        form.append("response_format", "json");

          method: "POST",

      throw new ExtractError(
        "SOURCE_EMPTY",
        "No speech was found in that recording.",

  private jsonHeaders(): Record<string, string> {
    return { ...this.authHeaders(), "content-type": "application/json" };
  }

  private authHeaders(): Record<string, string> {
    if (!this.configured) {
      throw new AiError(
        "AI_NOT_CONFIGURED",
        "AI is not configured. Set OPENAI_API_KEY on the API and restart it.",
      );
    }

    return { authorization: `Bearer ${this.key}` };
  }

  /**
   * One request, three attempts. The body is built per attempt so a retried
   * upload gets a fresh FormData; a rejected key and a refused parameter are
   * not retried, because nothing about them changes.
   */
  private async request(
    path: string,
    attempts: number,
    build: () => RequestInit,
  ): Promise<unknown> {
    let last: unknown = null;

    for (let attempt = 1; attempt <= attempts; attempt += 1) {
      let response: Response;

      try {
        response = await fetch(`${this.base}${path}`, build());
      } catch (error) {
        last = error;
        if (attempt === attempts) break;
        await sleep(BACKOFF_MS * attempt);
        continue;
      }

      if (response.ok) return response.json();

      const detail = await sentenceOf(response);

      if (response.status === 401 || response.status === 403) {
        throw new AiError(
          "AI_UNAUTHORIZED",
          `OpenAI rejected the API key. ${detail}`,
        );
      }

      if (response.status === 429) {
        last = new AiError(
          "AI_RATE_LIMITED",
          `OpenAI is rate limiting this key. ${detail}`,
          true,
        );
        if (attempt === attempts) break;
        // A 429 asks for a longer pause than a dropped socket.
        await sleep(BACKOFF_MS * attempt * 3);
        continue;
      }

      if (response.status >= 500) {
        last = new AiError("AI_UNAVAILABLE", `OpenAI failed. ${detail}`, true);
        if (attempt === attempts) break;
        await sleep(BACKOFF_MS * attempt);
        continue;
      }

      throw new AiError("AI_UNAVAILABLE", `OpenAI refused the request. ${detail}`);
    }

    if (last instanceof AiError) throw last;

    throw new AiError(
      "AI_UNAVAILABLE",
      `Could not reach OpenAI. ${last instanceof Error ? last.message : "unknown failure"}`,
      true,
    );
  }
}

/** OpenAI answers `{ error: { message } }`; anything else is a gateway. */
async function sentenceOf(response: Response): Promise<string> {
  const body = (await response.json().catch(() => null)) as ChatBody | null;
  const message = body?.error?.message;

  if (typeof message === "string" && message.trim().length > 0) {
    return message.trim();
  }

  return `HTTP ${response.status}.`;
}

function sleep(ms: number): Promise<void> {
  return new Promise((resolve) => setTimeout(resolve, ms));
}
```

```ts
/**
 * Splitting text for retrieval.
 *
 * Characters stand in for tokens: there is no tokenizer in the dependency
 * list, and 3,200 characters is close enough to 800 tokens that retrieval
 * quality does not notice. A boundary in the last 300 characters is preferred
 * so a chunk rarely starts mid-sentence, and 480 characters of overlap keep an
 * answer that straddles a cut visible to both chunks.
 */
export const CHUNK_CHARS = 3_200;
export const OVERLAP_CHARS = 480;
export const MAX_CHUNKS = 5_000;

const BOUNDARY_LOOKBACK = 300;

export function splitText(raw: string): string[] {
  const text = raw.replace(/\r\n?/g, "\n").trim();

  if (text.length === 0) return [];
  if (text.length <= CHUNK_CHARS) return [text];

  const chunks: string[] = [];
  let start = 0;

  while (start < text.length) {
    const hard = Math.min(start + CHUNK_CHARS, text.length);
    const end =
      hard < text.length
        ? (boundaryOf(
            text,
            Math.max(start + CHUNK_CHARS - BOUNDARY_LOOKBACK, start + 1),
            hard,
          ) ?? hard)
        : hard;

    const piece = text.slice(start, end).trim();
    if (piece.length > 0) chunks.push(piece);

    if (end >= text.length) break;

    // Always forward: a boundary found far back would otherwise loop forever.
    start = Math.max(end - OVERLAP_CHARS, start + 1);
  }

  return chunks;
}

/** A paragraph, then a sentence, then a line, then nothing. */
function boundaryOf(text: string, from: number, to: number): number | null {
  const window = text.slice(from, to);

  const paragraph = window.lastIndexOf("\n\n");
  if (paragraph >= 0) return from + paragraph + 2;

  const sentence = Math.max(
    window.lastIndexOf(". "),
    window.lastIndexOf("? "),
    window.lastIndexOf("! "),
  );
  if (sentence >= 0) return from + sentence + 2;

  const line = window.lastIndexOf("\n");
  if (line >= 0) return from + line + 1;

  return null;
}

/** Four characters per token is the usual English average, and an estimate. */
export function estimateTokens(text: string): number {
  return Math.ceil(text.length / 4);
}
```

**Interfaces:**

```ts
import * as ExcelJS from "exceljs";
import mammoth from "mammoth";

import { ExtractError } from "./ai.errors";

/**
 * Turning an uploaded file into text.
 *
 * Every reader here is pure JavaScript and runs in this process: the Render
 * build stays `npm ci && npm run build` with no LibreOffice, no container and
 * no native module. `.xls` is deliberately absent — `exceljs` reads the
 * zipped `.xlsx` format only.
 */
export const DOCUMENT_EXTENSIONS = [
  "txt",
  "md",
  "csv",
  "docx",
  "xlsx",
  "pdf",
] as const;

export function extensionOf(name: string): string {
  const at = name.lastIndexOf(".");

  return at >= 0 ? name.slice(at + 1).toLowerCase() : "";
}

export async function extractDocument(file: {
  bytes: Buffer;
  mime: string;
  name: string;
}): Promise<string> {
  const extension = extensionOf(file.name);

  switch (extension) {
    case "txt":
    case "md":
      return expectText(decode(file.bytes), "That file was empty.");

    case "csv":
      return expectText(csvToText(decode(file.bytes)), "That CSV was empty.");

    case "docx":
      return expectText(await docxText(file.bytes), "That document was empty.");

    case "xlsx":
      return expectText(await sheetText(file.bytes), "That workbook was empty.");

    case "xls":
      throw new ExtractError(
        "SOURCE_UNSUPPORTED",
        "The old .xls format cannot be read. Open it in Excel and save it as .xlsx, then upload that.",
      );

    case "pdf":
      return expectText(await pdfText(file.bytes), "That PDF was empty.");

    default:
      throw new ExtractError(
        "SOURCE_UNSUPPORTED",
        `A ${extension ? `.${extension}` : "file of that type"} is not one the agent can read.`,
      );
  }
}

/** UTF-8, with the byte-order mark an exported CSV often carries. */
function decode(bytes: Buffer): string {
  return bytes.toString("utf8").replace(/^\uFEFF/, "").trim();
}

function expectText(text: string, sentence: string): string {
  const trimmed = text.trim();

  if (trimmed.length === 0) throw new ExtractError("SOURCE_EMPTY", sentence);

  return trimmed;
}

/**
 * A CSV loses its meaning when the commas stay in: "Delivery,50" reads as one
 * phrase. Cells joined with a separator read as a row, which is what a person
 * asking "how much is delivery" is searching for. Quoted cells are respected.
 */
function csvToText(raw: string): string {
  return raw
    .split(/\r?\n/)
    .map((line) => cellsOf(line).join(" | ").trim())
    .filter((line) => line.replace(/\|/g, "").trim().length > 0)
    .join("\n");
}

function cellsOf(line: string): string[] {
  const cells: string[] = [];
  let cell = "";
  let quoted = false;

  for (let index = 0; index < line.length; index += 1) {
    const char = line[index];

    if (char === '"') {
      // A doubled quote inside a quoted cell is one literal quote.
      if (quoted && line[index + 1] === '"') {
        cell += '"';
        index += 1;
      } else {
        quoted = !quoted;
      }
      continue;
    }

    if (char === "," && !quoted) {
      cells.push(cell.trim());
      cell = "";
      continue;
    }

    cell += char;
  }

  cells.push(cell.trim());

  return cells.filter((value) => value.length > 0);
}

async function docxText(bytes: Buffer): Promise<string> {
  const result = await mammoth.extractRawText({ buffer: bytes });

  return result.value.trim();
}

/** One heading per sheet, then each row's cells on one line. */
async function sheetText(bytes: Buffer): Promise<string> {
  const workbook = new ExcelJS.Workbook();

  await workbook.xlsx.load(bytes);

  const sheets: string[] = [];

  for (const sheet of workbook.worksheets) {
    const lines: string[] = [];

    sheet.eachRow({ includeEmpty: false }, (row) => {
      const cells: string[] = [];

      row.eachCell({ includeEmpty: false }, (cell) => {
        const text = String(cell.text ?? "").trim();
        if (text.length > 0) cells.push(text);
      });

      if (cells.length > 0) lines.push(cells.join(" | "));
    });

    if (lines.length > 0) sheets.push(`## ${sheet.name}\n${lines.join("\n")}`);
  }

  return sheets.join("\n\n");
}

/**
 * The text layer only. No page is rendered, so no canvas is needed — and a
 * scanned PDF, which has no text layer, cannot be read at all until a renderer
 * exists. It says so instead of indexing nothing.
 */
async function pdfText(bytes: Buffer): Promise<string> {
  const pdfjs = await import("pdfjs-dist");

  const document = await pdfjs
    .getDocument({
      data: new Uint8Array(bytes),
      isEvalSupported: false,
      useSystemFonts: false,
      disableFontFace: true,
    })
    .promise;

  const pages: string[] = [];

  try {
    for (let number = 1; number <= document.numPages; number += 1) {
      const page = await document.getPage(number);
      const content = await page.getTextContent();

      const line = content.items
        .map((item) => ("str" in item ? item.str : ""))
        .join(" ")
        .replace(/\s+/g, " ")
        .trim();

      if (line.length > 0) pages.push(line);

      page.cleanup();
    }
  } finally {
    await document.destroy();
  }

  if (pages.length === 0) {
    throw new ExtractError(
      "SOURCE_UNSUPPORTED",
      "That PDF has no text layer, so nothing could be read. It is probably a scan; upload page images or a text export instead.",
    );
  }

  return pages.join("\n\n");
}
```

```ts
const MIME_BY_EXTENSION: Record<string, string> = {
  flac: "audio/flac",
  gif: "image/gif",
  jpeg: "image/jpeg",
  jpg: "image/jpeg",
  m4a: "audio/mp4",
  mp3: "audio/mpeg",
  mp4: "audio/mp4",
  oga: "audio/ogg",
  ogg: "audio/ogg",
  png: "image/png",
  wav: "audio/wav",
  webm: "audio/webm",
  webp: "image/webp",
};

/**
 * The one place an image or a voice note becomes text.
 *
 * Both halves are the same OpenAI key as the reply engine: vision is the
 * agent's own chat model (it is multimodal — verified), and transcription is
 * `whisper-1`. Video is refused here rather than accepted and dropped.
 */
@Injectable()
export class OpenAiMediaExtractor {
  constructor(private readonly provider: OpenAiProvider) {}

  async read(input: {
    bytes: Buffer;
    mime: string;
    name: string;
    /** The agent's model, so vision is read by the model that will answer. */
    model: string;
  }): Promise<{ text: string }> {
    const mime = this.mimeOf(input);

    if (IMAGE_MIMES.has(mime) || mime.startsWith("image/")) {
      const result = await this.provider.describeImage({
        bytes: input.bytes,
        mime,
        model: input.model,
      });

      return { text: result.text };
    }

    if (mime.startsWith("video/")) {
      throw new ExtractError(
        "SOURCE_UNSUPPORTED",
        "Video training arrives in a later release. Upload a document, an image or a voice note for now.",
      );
    }

    if (AUDIO_MIMES.has(mime) || mime.startsWith("audio/")) {
      if (!AUDIO_MIMES.has(mime)) {
        throw new ExtractError(
          "SOURCE_UNSUPPORTED",
          `Whisper cannot read ${mime}. Convert the recording to mp3, m4a, ogg or wav and upload that.`,
        );
      }

      return this.provider.transcribe({
        bytes: input.bytes,
        mime,
        name: input.name,
      });
    }

    throw new ExtractError(
      "SOURCE_UNSUPPORTED",
      "That file type is not one the agent can read.",
    );
  }

  private mimeOf(input: { mime: string; name: string }): string {
    const declared = input.mime.toLowerCase().split(";")[0].trim();

    if (declared.includes("/")) return declared;

    return MIME_BY_EXTENSION[extensionOf(input.name)] ?? "";
  }
}
```

```ts
import { randomUUID } from "node:crypto";

import {
  ConflictException,
  Injectable,
  Logger,
  NotFoundException,
} from "@nestjs/common";

import type { AuthClaims } from "../auth/auth.types";
import { PrismaService } from "../prisma/prisma.service";
import { WorkspacesService } from "../workspaces/workspaces.service";
import type { UploadedMedia } from "../inbox/inbox.sender";
import { MediaStorage } from "../inbox/media.storage";
import { AiError, ExtractError } from "./ai.errors";
import { OpenAiProvider, toVector } from "./ai.openai";
import { extractDocument, extensionOf } from "./extract";
import { OpenAiMediaExtractor } from "./extract.media";
import {
  MAX_CHUNKS,
  estimateTokens,
  splitText,
} from "./knowledge.chunk";
import type { AddTextSourceDto } from "./dto/add-text-source.dto";

/** The same ceiling the inbox uses for what leaves, applied to what arrives. */
export const MAX_SOURCE_BYTES = 25 * 1024 * 1024;

/** Chunks per embedding call. Verified: one call returns many vectors. */
const EMBED_BATCH = 32;

/** A row stuck in PROCESSING for this long belongs to a process that died. */
const STALE_MS = 10 * 60 * 1000;

/** Automatic attempts before a source is left FAILED for a human to retry. */
const MAX_ATTEMPTS = 2;

export interface SourceView {
  id: string;
  kind: "TEXT" | "FILE";
  title: string;
  mime: string | null;
  size: number | null;
  status: "PENDING" | "PROCESSING" | "READY" | "FAILED";
  error: string | null;
  charCount: number;
  chunkCount: number;
  embedTokens: number;
  indexedAt: string | null;
  createdAt: string;
}

/**
 * The knowledge base: where a file becomes a row of vectors.
 *
 * Uploads write the bytes and a PENDING row in the request; the work happens in
 * `AgentsRunner`, because a 1,200-chunk price book is forty embedding calls and
 * no HTTP request should own that. Extraction is additive — the text is kept on
 * the source so re-embedding never asks for the file again.
 */
@Injectable()
export class KnowledgeService {
  private readonly logger = new Logger(KnowledgeService.name);

  constructor(
    private readonly prisma: PrismaService,
    private readonly workspaces: WorkspacesService,
    private readonly storage: MediaStorage,
    private readonly provider: OpenAiProvider,
    private readonly media: OpenAiMediaExtractor,
  ) {}

  async addText(
    claims: AuthClaims,
    agentId: string,
    dto: AddTextSourceDto,
  ): Promise<{ source: SourceView }> {
    const { workspaceId } = await this.workspaces.primaryFor(claims);
    const agent = await this.agentOf(workspaceId, agentId);

    const row = await this.prisma.knowledgeSource.create({
      data: {
        agentId: agent.id,
        kind: "TEXT",
        title: dto.title,
        text: dto.body,
        charCount: dto.body.length,
        status: "PENDING",
      },
    });

    return { source: sourceView(row) };
  }

  async addFile(
    claims: AuthClaims,
    agentId: string,
    file: UploadedMedia,
  ): Promise<{ source: SourceView }> {
    const { workspaceId } = await this.workspaces.primaryFor(claims);
    const agent = await this.agentOf(workspaceId, agentId);

    if (file.size > MAX_SOURCE_BYTES) {
      throw new ConflictException({
        code: "SOURCE_TOO_LARGE",
        message: "Training files are limited to 25 MB.",
      });
    }

    // The id is chosen here so the storage path can be written before the row:
    // an upload that lands without a row is garbage, and a row without an
    // upload is a retry that can never work.
    const id = randomUUID();
    const path = `agents/${workspaceId}/${agentId}/${id}.${extensionOf(file.originalname) || "bin"}`;

    await this.storage.upload(path, file.buffer, file.mimetype || "application/octet-stream");

    try {
      const row = await this.prisma.knowledgeSource.create({
        data: {
          id,
          agentId: agent.id,
          kind: "FILE",
          title: file.originalname || "Untitled file",
          mime: file.mimetype || null,
          size: file.size,
          storagePath: path,
          status: "PENDING",
        },
      });

      return { source: sourceView(row) };
    } catch (error) {
      // No row will ever name these bytes, so they must not stay billed.
      await this.storage.remove([path]);
      throw error;
    }
  }

  async list(claims: AuthClaims, agentId: string): Promise<{ sources: SourceView[] }> {
    const { workspaceId } = await this.workspaces.primaryFor(claims);
    const agent = await this.agentOf(workspaceId, agentId);

    const rows = await this.prisma.knowledgeSource.findMany({
      where: { agentId: agent.id },
      orderBy: { createdAt: "desc" },
    });

    return { sources: rows.map(sourceView) };
  }

  async remove(
    claims: AuthClaims,
    agentId: string,
    sourceId: string,
  ): Promise<{ deleted: true }> {
    const { workspaceId } = await this.workspaces.primaryFor(claims);
    const agent = await this.agentOf(workspaceId, agentId);
    const source = await this.sourceOf(agent.id, sourceId);

    // Chunks go with the row (cascade). The stored original has no foreign key.
    await this.prisma.knowledgeSource.delete({ where: { id: source.id } });

    if (source.storagePath) await this.storage.remove([source.storagePath]);

    return { deleted: true };
  }

  async retry(
    claims: AuthClaims,
    agentId: string,
    sourceId: string,
  ): Promise<{ source: SourceView }> {
    const { workspaceId } = await this.workspaces.primaryFor(claims);
    const agent = await this.agentOf(workspaceId, agentId);
    const source = await this.sourceOf(agent.id, sourceId);

    const row = await this.prisma.knowledgeSource.update({
      where: { id: source.id },
      data: {
        status: "PENDING",
        error: null,
        attempts: 0,
        // A file is re-read from storage; a typed note keeps its text.
        ...(source.kind === "FILE" ? { text: null } : {}),
      },
    });

    return { source: sourceView(row) };
  }

  /** The workspace's agent, or a 404 that another tenant's id also gets. */
  async agentOf(workspaceId: string, agentId: string) {
    const agent = await this.prisma.agent.findFirst({
      where: { id: agentId, workspaceId },
      select: {
        id: true,
        workspaceId: true,
        name: true,
        model: true,
        isActive: true,
        whatsappAccountId: true,
      },
    });

    if (!agent) throw new NotFoundException("That agent does not exist.");

    return agent;
  }

  private async sourceOf(agentId: string, sourceId: string) {
    const source = await this.prisma.knowledgeSource.findFirst({
      where: { id: sourceId, agentId },
      select: { id: true, kind: true, storagePath: true },
    });

    if (!source) throw new NotFoundException("That source does not exist.");

    return source;
  }

  /**
   * Claim one pending source. The statement is the lock: two runners waking at
   * the same instant cannot both take it, and `SKIP LOCKED` keeps the second
   * from waiting on the first.
   */
  async claim(): Promise<string | null> {
    const rows = await this.prisma.$queryRaw<{ id: string }[]>`
      UPDATE knowledge_sources
      SET status = 'PROCESSING', updated_at = now()
      WHERE id = (
        SELECT id FROM knowledge_sources
        WHERE status = 'PENDING'
        ORDER BY created_at ASC
        LIMIT 1
        FOR UPDATE SKIP LOCKED
      )
      RETURNING id
    `;

    return rows[0]?.id ?? null;
  }

  /**
   * Extract, split, embed, mark READY. Never throws: a runner tick that dies
   * here would stop every other source behind it.
   */
  async index(sourceId: string): Promise<void> {
    const source = await this.prisma.knowledgeSource.findUnique({
      where: { id: sourceId },
      select: {
        id: true,
        kind: true,
        title: true,
        mime: true,
        storagePath: true,
        text: true,
        status: true,
        agent: { select: { model: true } },
      },
    });

    if (!source || source.status !== "PROCESSING") return;

    try {
      const text =
        source.text && source.text.length > 0
          ? source.text
          : await this.readSource(source);

      const chunks = splitText(text);

      if (chunks.length === 0) {
        throw new ExtractError("SOURCE_EMPTY", "There was no readable text in that source.");
      }

      if (chunks.length > MAX_CHUNKS) {
        throw new ExtractError(
          "SOURCE_TOO_LARGE",
          `That document splits into ${chunks.length} chunks, over the ${MAX_CHUNKS} limit. Split it or upload the part that matters.`,
        );
      }

      // A retry re-reads from storage; the old chunks must not outlive it.
      await this.prisma.knowledgeChunk.deleteMany({ where: { sourceId: source.id } });

      await this.prisma.knowledgeChunk.createMany({
        data: chunks.map((chunk, ord) => ({
          sourceId: source.id,
          ord,
          text: chunk,
          tokens: estimateTokens(chunk),
        })),
      });

      const rows = await this.prisma.knowledgeChunk.findMany({
        where: { sourceId: source.id },
        orderBy: { ord: "asc" },
        select: { id: true, text: true },
      });

      let embedTokens = 0;

      for (let at = 0; at < rows.length; at += EMBED_BATCH) {
        const batch = rows.slice(at, at + EMBED_BATCH);
        const embedded = await this.provider.embed(batch.map((row) => row.text));

        embedTokens += embedded.tokens;

        await this.prisma.$transaction(
          batch.map((row, index) =>
            this.prisma.$executeRaw`
              UPDATE knowledge_chunks
              SET embedding = ${toVector(embedded.vectors[index])}::vector
              WHERE id = ${row.id}::uuid
            `,
          ),
        );
      }

      await this.prisma.knowledgeSource.update({
        where: { id: source.id },
        data: {
          text,
          charCount: text.length,
          chunkCount: rows.length,
          embedTokens,
          status: "READY",
          error: null,
          indexedAt: new Date(),
        },
      });

      this.logger.log(
        `Indexed ${rows.length} chunks for source ${source.id} (${source.title}).`,
      );
    } catch (error) {
      await this.fail(source.id, error);
    }
  }

  private async readSource(source: {
    id: string;
    kind: "TEXT" | "FILE";
    title: string;
    mime: string | null;
    storagePath: string | null;
    agent: { model: string };
  }): Promise<string> {
    if (source.kind === "TEXT") {
      throw new ExtractError("SOURCE_EMPTY", "That note had no text.");
    }

    if (!source.storagePath) {
      throw new ExtractError(
        "SOURCE_EMPTY",
        "This source has no stored file to read. Upload it again.",
      );
    }

    const bytes = await this.storage.download(source.storagePath);
    const mime = source.mime ?? "";

    if (mime.startsWith("image/") || mime.startsWith("audio/") || mime.startsWith("video/")) {
      return (await this.media.read({
        bytes,
        mime,
        name: source.title,
        model: source.agent.model,
      })).text;
    }

    return extractDocument({ bytes, mime, name: source.title });
  }

  /**
   * A failed source keeps its reason and loses its chunks: a half-indexed file
   * that answers is worse than one that says it could not be read.
   */
  private async fail(sourceId: string, error: unknown): Promise<void> {
    const message =
      error instanceof ExtractError || error instanceof AiError
        ? error.message
        : error instanceof Error
          ? error.message
          : "Extraction failed.";

    this.logger.warn(`Source ${sourceId} failed: ${message}`);

    await this.prisma.knowledgeChunk
      .deleteMany({ where: { sourceId } })
      .catch(() => undefined);

    await this.prisma.knowledgeSource
      .update({
        where: { id: sourceId },
        data: { status: "FAILED", error: message, chunkCount: 0 },
      })
      .catch(() => undefined);
  }

  /**
   * Return rows whose process died. Measured on `updatedAt`, so no second
   * timestamp column is needed; the capped ones are left FAILED rather than
   * looped forever.
   */
  async recoverStale(): Promise<void> {
    const cut = new Date(Date.now() - STALE_MS);

    await this.prisma.knowledgeSource.updateMany({
      where: {
        status: "PROCESSING",
        updatedAt: { lt: cut },
        attempts: { gte: MAX_ATTEMPTS - 1 },
      },
      data: {
        status: "FAILED",
        error: "Indexing was interrupted repeatedly and will not be retried automatically. Use Retry.",
      },
    });

    await this.prisma.knowledgeSource.updateMany({
      where: { status: "PROCESSING", updatedAt: { lt: cut } },
      data: { status: "PENDING", attempts: { increment: 1 } },
    });
  }
}

export function sourceView(row: {
  id: string;
  kind: "TEXT" | "FILE";
  title: string;
  mime: string | null;
  size: number | null;
  status: "PENDING" | "PROCESSING" | "READY" | "FAILED";
  error: string | null;
  charCount: number;
  chunkCount: number;
  embedTokens: number;
  indexedAt: Date | null;
  createdAt: Date;
}): SourceView {
  return {
    id: row.id,
    kind: row.kind,
    title: row.title,
    mime: row.mime,
    size: row.size,
    status: row.status,
    error: row.error,
    charCount: row.charCount,
    chunkCount: row.chunkCount,
    embedTokens: row.embedTokens,
    indexedAt: row.indexedAt ? row.indexedAt.toISOString() : null,
    createdAt: row.createdAt.toISOString(),
  };
}
```

```ts
import { Injectable } from "@nestjs/common";

import { PrismaService } from "../prisma/prisma.service";
import { OpenAiProvider, toVector } from "./ai.openai";

/** How many chunks the prompt can carry before it stops being one answer. */
export const TOP_K = 6;

/**
 * Below this a match is noise. It is deliberately low: a fixed threshold is
 * model- and corpus-dependent, and a high one would silently refuse questions
 * the material does answer. The floor only drops near-zero matches.
 */
export const FLOOR = 0.25;

export interface ContextChunk {
  id: string;
  text: string;
  sourceId: string;
  title: string;
  /** Cosine similarity, 0 to 1. */
  score: number;
}

interface Row {
  id: string;
  text: string;
  source_id: string;
  title: string;
  score: number;
}

/**
 * Cosine search over one agent's READY chunks.
 *
 * `iterative_scan` is why pgvector 0.8 matters: the filter is applied after the
 * index scan, so without it a busy table returns fewer than six rows whenever
 * other agents' chunks crowd the neighbourhood. On a multi-tenant install that
 * is a correctness bug, not a tuning knob.
 */
@Injectable()
export class RetrievalService {
  constructor(
    private readonly prisma: PrismaService,
    private readonly provider: OpenAiProvider,
  ) {}

  async search(
    agentId: string,
    question: string,
  ): Promise<{ chunks: ContextChunk[]; embedTokens: number }> {
    const { vectors, tokens } = await this.provider.embed([question]);
    const vector = toVector(vectors[0]);

    // `SET LOCAL` only applies inside a transaction, and both statements have
    // to share one connection. The array form is one connection and one
    // transaction — unlike the interactive form this codebase avoids on the
    // Supabase pooler.
    const [, rows] = await this.prisma.$transaction([
      this.prisma.$executeRawUnsafe(
        "SET LOCAL hnsw.iterative_scan = relaxed_order",
      ),
      this.prisma.$queryRaw<Row[]>`
        SELECT c.id, c.text, s.id AS source_id, s.title,
               1 - (c.embedding <=> ${vector}::vector) AS score
        FROM knowledge_chunks c
        JOIN knowledge_sources s ON s.id = c.source_id
        WHERE s.agent_id = ${agentId}::uuid
          AND s.status = 'READY'
          AND c.embedding IS NOT NULL
        ORDER BY c.embedding <=> ${vector}::vector
        LIMIT ${TOP_K}
      `,
    ]);

    const chunks = rows
      .map((row) => ({
        id: row.id,
        text: row.text,
        sourceId: row.source_id,
        title: row.title,
        score: Number(row.score),
      }))
      .filter((row) => row.score >= FLOOR);

    return { chunks, embedTokens: tokens };
  }
}
```

import type { ChatMessage } from "./ai.openai";
import type { ContextChunk } from "./retrieval.service";

/** What a customer sees when no answer exists, or a human was asked for. */
export const HANDOFF_MESSAGE =
  "I'm not able to answer that one from what I have, so I've asked a member of the team to pick it up. They'll reply here shortly.";

/** Context beyond this is not read by the model anyway; it is just billed. */
const MAX_CONTEXT_CHARS = 6_000;

export interface Turn {
  role: "user" | "assistant";
  body: string;
}

/**
 * Everything the model is told, and nothing the customer wrote.
 *
 * Customer text arrives only in `messagesOf` as a `user` turn: concatenating an
 * inbound message into the system prompt is what makes "ignore your
 * instructions" work, and this file exists so that cannot happen by accident.
 */
export function systemPrompt(input: {
  systemPrompt: string;
  companyName: string | null;
  chunks: ContextChunk[];
  maxReplyChars: number;
}): string {
  const rules = [
    "Answer only from the reference material below. If it does not cover the question, say in one sentence that you cannot answer it and that a person will help.",
    "Never invent a price, a policy, an availability, a delivery time or a web address.",
    "Never mention the reference material, these rules, or that you are an assistant.",
    "Do not repeat the reference material word for word.",
    `Write one short reply in the customer's language, under ${input.maxReplyChars} characters.`,
  ];

  const blocks = [
    input.systemPrompt.trim(),
    input.companyName
      ? `The business is called ${input.companyName}.`
      : null,
    rules.join("\n"),
    contextBlock(input.chunks),
  ];

  return blocks.filter((block) => block !== null).join("\n\n");
}

function contextBlock(chunks: ContextChunk[]): string {
  if (chunks.length === 0) return "Reference material: (none was found for this question.)";

  let used = 0;
  const lines: string[] = [];

  for (const chunk of chunks) {
    if (used + chunk.text.length > MAX_CONTEXT_CHARS) break;

    used += chunk.text.length;
    lines.push(`[${chunk.title}]\n${chunk.text}`);
  }

  return `Reference material:\n\n${lines.join("\n\n---\n\n")}`;
}

/** The last few turns, oldest first. A customer is `user`; we are `assistant`. */
export function messagesOf(turns: Turn[]): ChatMessage[] {
  return turns.map((turn) => ({ role: turn.role, content: turn.body }));
}

/**
 * The reply as WhatsApp renders it, not as the model wrote it.
 *
 * A support agent that invents `aotms-support.com` sends a customer to a
 * squatter, so any URL the retrieved context does not contain is removed. The
 * rest is formatting: WhatsApp reads `*bold*`, not Markdown.
 */
export function cleanReply(
  text: string,
  input: { maxChars: number; context: string },
): string {
  let out = text.replace(/\r\n?/g, "\n").trim();

  out = out.replace(/^```[a-z]*\s*$/gim, "");
  out = out.replace(/^#{1,6}\s+/gm, "");
  out = out.replace(/\*\*(.+?)\*\*/g, "*$1*");
  out = out.replace(/__(.+?)__/g, "_$1_");
  out = out
    .split("\n")
    .map((line) => line.replace(/[ \t]+$/g, ""))
    .join("\n");
  out = out.replace(/\n{3,}/g, "\n\n");
  out = out.replace(/[ \t]{2,}/g, " ");
  out = stripUnknownLinks(out, input.context).trim();

  if (out.length > input.maxChars) out = truncateAtSentence(out, input.maxChars);

  return out;
}

const LINK = /\b(?:https?:\/\/|www\.)[^\s)]+|[\w-]+(?:\.[\w-]+)*\.(?:com|net|org|io|co|in|uk|lk|ae|de|fr|es|it|info|biz|shop|store|app|dev|me)\b[^\s)]*/gi;

function stripUnknownLinks(text: string, context: string): string {
  const haystack = context.toLowerCase();

  return text
    .replace(LINK, (match) =>
      haystack.includes(match.toLowerCase()) ? match : "",
    )
    .replace(/[ \t]{2,}/g, " ")
    .replace(/\(\s*\)/g, "")
    .trim();
}

/** Cut on a sentence, then a line, then a space — never mid-word. */
function truncateAtSentence(text: string, maxChars: number): string {
  const head = text.slice(0, maxChars);
  const window = head.slice(Math.max(0, head.length - 200));

  const sentence = Math.max(
    window.lastIndexOf(". "),
    window.lastIndexOf("? "),
    window.lastIndexOf("! "),
  );

  if (sentence >= 0) {
    const at = head.length - window.length + sentence + 1;
    return head.slice(0, at).trim();
  }

  const line = head.lastIndexOf("\n");
  if (line > 0) return head.slice(0, line).trim();

  const space = head.lastIndexOf(" ");
  return (space > 0 ? head.slice(0, space) : head).trim();
}

/** A keyword the operator said a human must see, matched whole-word. */
export function matchesEscalation(text: string, keywords: string[]): boolean {
  if (keywords.length === 0) return false;

  const lower = text.toLowerCase();

  return keywords.some((keyword) => {
    const needle = keyword.trim().toLowerCase();
    if (needle.length === 0) return false;

    const at = lower.indexOf(needle);
    if (at < 0) return false;

    const before = at === 0 ? " " : lower[at - 1];
    const after = at + needle.length >= lower.length ? " " : lower[at + needle.length];

    return !/[\p{L}\p{N}]/u.test(before) && !/[\p{L}\p{N}]/u.test(after);
  });
}

```ts
  "You answer customer questions for this business in WhatsApp. Be brief, warm and specific.";

/**
 * The agent's own surface: what it is, whether it answers, and what it costs.
 *
 * Activation is a transaction because "one active per number" is two writes —
 * deactivate the sibling, activate this one — and the partial unique index
 * would refuse the second if the first had not happened.
 */
@Injectable()
export class AgentsService {
  constructor(
    private readonly prisma: PrismaService,
    private readonly workspaces: WorkspacesService,
    private readonly knowledge: KnowledgeService,
    private readonly retrieval: RetrievalService,
    private readonly provider: OpenAiProvider,
  ) {}

  async list(claims: AuthClaims): Promise<AgentList> {
    const { workspaceId } = await this.workspaces.primaryFor(claims);

    // The number travels with the list because the screen's header names it,
    // and a second request for it would be a second tenant lookup that could
    // disagree with this one.
    const [rows, account] = await Promise.all([
      this.prisma.agent.findMany({
        where: { workspaceId },
        orderBy: { createdAt: "asc" },
        include: { _count: { select: { sources: true } } },
      }),
      this.prisma.whatsAppAccount.findUnique({
        where: { workspaceId },
        select: { displayPhoneNumber: true, phoneNumberId: true },
      }),
    ]);

    const ready = await this.prisma.knowledgeSource.groupBy({
      by: ["agentId"],
      where: { agentId: { in: rows.map((row) => row.id) }, status: "READY" },
      _count: { _all: true },
    });

    const index = new Map(ready.map((row) => [row.agentId, row._count._all]));

    return {
      agents: rows.map((row) => agentView(row, index.get(row.id) ?? 0)),
      channel: account
        ? { display: account.displayPhoneNumber, phoneNumberId: account.phoneNumberId }
        : null,
    };
  }

  async create(claims: AuthClaims, dto: CreateAgentDto): Promise<{ agent: AgentView }> {
    const { workspaceId, userId } = await this.workspaces.primaryFor(claims);

    const account = await this.prisma.whatsAppAccount.findUnique({
      where: { workspaceId },
      select: { id: true },
    });

    if (!account) {
      throw new ConflictException({
        code: "NO_CHANNEL",
        message: "Connect a WhatsApp number before creating an agent.",
      });
    }

    const row = await this.prisma.agent.create({
      data: {
        workspaceId,
        whatsappAccountId: account.id,
        name: dto.name,
        description: dto.description ?? null,
        systemPrompt: dto.systemPrompt ?? DEFAULT_PROMPT,
        model: dto.model ?? DEFAULT_CHAT_MODEL,
        temperature: dto.temperature ?? 0.4,
        maxReplyChars: dto.maxReplyChars ?? 900,
        escalateKeywords: dto.escalateKeywords ?? [],
        createdByUserId: userId,
      },
      include: { _count: { select: { sources: true } } },
    });

    return { agent: agentView(row, 0) };
  }

  async detail(claims: AuthClaims, id: string): Promise<AgentDetail> {
    const { workspaceId } = await this.workspaces.primaryFor(claims);
    const agent = await this.knowledge.agentOf(workspaceId, id);

    const [sources, totals, runs, ready] = await Promise.all([
      this.prisma.knowledgeSource.findMany({
        where: { agentId: agent.id },
        orderBy: { createdAt: "desc" },
      }),
      this.prisma.agentRun.aggregate({
        where: { agentId: agent.id },
        _count: { _all: true },
        _sum: { tokensIn: true, tokensOut: true, embeddingTokens: true },
      }),
      this.prisma.agentRun.findMany({
        where: { agentId: agent.id },
        orderBy: { createdAt: "desc" },
        take: 20,
      }),
      this.prisma.knowledgeSource.count({ where: { agentId: agent.id, status: "READY" } }),
    ]);

    return {
      agent: agentView({ ...agent, _count: { sources: sources.length } }, ready),
      sources: sources.map(sourceView),
      usage: usageOf(totals),
      runs: runs.map(runView),
    };
  }

  async update(
    claims: AuthClaims,
    id: string,
    dto: UpdateAgentDto,
  ): Promise<{ agent: AgentView }> {
    const { workspaceId } = await this.workspaces.primaryFor(claims);
    const agent = await this.knowledge.agentOf(workspaceId, id);

    // Activation is its own route: a PATCH that could activate would bypass
    // the "one READY source" rule.
    const { isActive: _ignored, ...changes } = dto;

    const row = await this.prisma.agent.update({
      where: { id: agent.id },
      data: {
        ...(changes.name !== undefined ? { name: changes.name } : {}),
        ...(changes.description !== undefined ? { description: changes.description } : {}),
        ...(changes.systemPrompt !== undefined ? { systemPrompt: changes.systemPrompt } : {}),
        ...(changes.model !== undefined ? { model: changes.model } : {}),
        ...(changes.temperature !== undefined ? { temperature: changes.temperature } : {}),
        ...(changes.maxReplyChars !== undefined ? { maxReplyChars: changes.maxReplyChars } : {}),
        ...(changes.escalateKeywords !== undefined
          ? { escalateKeywords: changes.escalateKeywords }
          : {}),
      },
      include: { _count: { select: { sources: true } } },
    });

    const ready = await this.prisma.knowledgeSource.count({
      where: { agentId: agent.id, status: "READY" },
    });

    return { agent: agentView(row, ready) };
  }

  async remove(claims: AuthClaims, id: string): Promise<{ deleted: true }> {
    const { workspaceId } = await this.workspaces.primaryFor(claims);
    const agent = await this.knowledge.agentOf(workspaceId, id);

    const stored = await this.prisma.knowledgeSource.findMany({
      where: { agentId: agent.id, storagePath: { not: null } },
      select: { storagePath: true },
    });

    // Sources and runs go with the agent; the conversations it answered stay,
    // and `Message.agentId` is set null by the foreign key.
    await this.prisma.agent.delete({ where: { id: agent.id } });

    await this.storageRemove(stored.map((row) => row.storagePath).filter((path): path is string => path !== null));

    return { deleted: true };
  }

  async activate(claims: AuthClaims, id: string): Promise<{ agent: AgentView }> {
    const { workspaceId } = await this.workspaces.primaryFor(claims);
    const agent = await this.knowledge.agentOf(workspaceId, id);

    const ready = await this.prisma.knowledgeSource.count({
      where: { agentId: agent.id, status: "READY" },
    });

    if (ready === 0) {
      throw new ConflictException({
        code: "AGENT_UNTRAINED",
        message:
          "Add at least one source and wait for it to finish indexing before activating this agent.",
      });
    }

    await this.prisma.$transaction([
      this.prisma.agent.updateMany({
        where: { whatsappAccountId: agent.whatsappAccountId, isActive: true, id: { not: agent.id } },
        data: { isActive: false },
      }),
      this.prisma.agent.update({ where: { id: agent.id }, data: { isActive: true } }),
    ]);

    const row = await this.prisma.agent.findUniqueOrThrow({
      where: { id: agent.id },
      include: { _count: { select: { sources: true } } },
    });

    return { agent: agentView(row, ready) };
  }

  /**
   * The switch's off position. A single update, not the two writes activation
   * needs: turning off can never violate the partial unique index.
   */
  async deactivate(claims: AuthClaims, id: string): Promise<{ agent: AgentView }> {
    const { workspaceId } = await this.workspaces.primaryFor(claims);
    const agent = await this.knowledge.agentOf(workspaceId, id);

    await this.prisma.agent.update({
      where: { id: agent.id },
      data: { isActive: false },
    });

    const ready = await this.prisma.knowledgeSource.count({
      where: { agentId: agent.id, status: "READY" },
    });

    const row = await this.prisma.agent.findUniqueOrThrow({
      where: { id: agent.id },
      include: { _count: { select: { sources: true } } },
    });

    return { agent: agentView(row, ready) };
  }

  /**
   * The playground. Nothing is sent, but the call is a run, so it is metered
   * and it appears in Activity beside the replies.
   */
  async ask(claims: AuthClaims, id: string, dto: AskAgentDto): Promise<AskResult> {
    const { workspaceId } = await this.workspaces.primaryFor(claims);
    const agent = await this.knowledge.agentOf(workspaceId, id);

    this.requireProvider();

    const started = Date.now();
    const { chunks, embedTokens } = await this.retrieval.search(agent.id, dto.question);

    if (chunks.length === 0) {
      await this.record(agent.id, workspaceId, "SKIPPED", "no-context", {
        embeddingTokens: embedTokens,
        latencyMs: Date.now() - started,
      });

      return {
        answer: HANDOFF_MESSAGE,
        citations: [],
        tokens: { input: 0, output: 0, embedding: embedTokens },
        reason: "no-context",
      };
    }

    const company = await this.prisma.businessProfile.findFirst({
      where: { workspaceId },
      select: { companyName: true },
    });

    const full = await this.prisma.agent.findUniqueOrThrow({
      where: { id: agent.id },
      select: { systemPrompt: true, temperature: true, maxReplyChars: true, model: true },
    });

    try {
      const result = await this.provider.chat({
        model: full.model,
        system: systemPrompt({
          systemPrompt: full.systemPrompt,
          companyName: company?.companyName ?? null,
          chunks,
          maxReplyChars: full.maxReplyChars,
        }),
        messages: messagesOf([{ role: "user", body: dto.question }]),
        temperature: full.temperature,
        maxTokens: 400,
      });

      const answer = cleanReply(result.text, {
        maxChars: full.maxReplyChars,
        context: chunks.map((chunk) => chunk.text).join("\n\n"),
      });

      await this.record(agent.id, workspaceId, "SENT", null, {
        tokensIn: result.tokensIn,
        tokensOut: result.tokensOut,
        embeddingTokens: embedTokens,
        latencyMs: Date.now() - started,
      });

      return {
        answer,
        citations: chunks.map((chunk) => ({
          sourceId: chunk.sourceId,
          title: chunk.title,
          score: Math.round(chunk.score * 1000) / 1000,
          text: chunk.text.slice(0, 400),
        })),
        tokens: {
          input: result.tokensIn,
          output: result.tokensOut,
          embedding: embedTokens,
        },
        reason: null,
      };
    } catch (error) {
      await this.record(agent.id, workspaceId, "FAILED", null, {
        embeddingTokens: embedTokens,
        latencyMs: Date.now() - started,
        error: error instanceof Error ? error.message : "The model call failed.",
      });

      this.toHttp(error);
    }
  }

  async runs(claims: AuthClaims, id: string, query: ListRunsDto): Promise<{
    runs: RunView[];
    nextCursor: string | null;
    usage: Usage;
  }> {
    const { workspaceId } = await this.workspaces.primaryFor(claims);
    const agent = await this.knowledge.agentOf(workspaceId, id);
    const limit = query.limit ?? 30;

    // One `where` for the page and for the totals: the number above the table
    // always describes the rows the table can show, even when a cursor has
    // only fetched the first of them.
    const where = {
      agentId: agent.id,
      ...(query.kind ? { kind: query.kind } : {}),
      ...(query.status ? { status: query.status } : {}),
    };

    const [rows, totals] = await Promise.all([
      this.prisma.agentRun.findMany({
        where,
        orderBy: { createdAt: "desc" },
        take: limit + 1,
        ...(query.cursor ? { cursor: { id: query.cursor }, skip: 1 } : {}),
      }),
      this.prisma.agentRun.aggregate({
        where,
        _count: { _all: true },
        _sum: { tokensIn: true, tokensOut: true, embeddingTokens: true },
      }),
    ]);

    const page = rows.slice(0, limit);

    return {
      runs: page.map(runView),
      nextCursor: rows.length > limit ? (page[page.length - 1]?.id ?? null) : null,
      usage: usageOf(totals),
    };
  }

  /** A human pause, kept in the same three columns the takeover rule writes. */
  async pauseConversation(
    claims: AuthClaims,
    conversationId: string,
    reason: string,
  ): Promise<{ paused: true }> {
    const { workspaceId, userId } = await this.workspaces.primaryFor(claims);

    const updated = await this.prisma.conversation.updateMany({
      where: { id: conversationId, workspaceId },
      data: {
        aiPausedAt: new Date(),
        aiPausedByUserId: userId,
        aiPauseReason: reason,
      },
    });

    if (updated.count === 0) {
      throw new NotFoundException("That conversation does not exist.");
    }

    return { paused: true };
  }

  async resumeConversation(
    claims: AuthClaims,
    conversationId: string,
  ): Promise<{ paused: false }> {
    const { workspaceId } = await this.workspaces.primaryFor(claims);

    const updated = await this.prisma.conversation.updateMany({
      where: { id: conversationId, workspaceId },
      data: { aiPausedAt: null, aiPausedByUserId: null, aiPauseReason: null },
    });

    if (updated.count === 0) {
      throw new NotFoundException("That conversation does not exist.");
    }

    return { paused: false };
  }

  private requireProvider(): void {
    if (!this.provider.configured) {
      throw new ServiceUnavailableException({
        code: "AI_NOT_CONFIGURED",
        message: "AI is not configured. Set OPENAI_API_KEY on the API and restart it.",
      });
    }
  }

  private async record(
    agentId: string,
    workspaceId: string,
    status: AgentRunStatus,
    reason: string | null,
    numbers: {
      tokensIn?: number;
      tokensOut?: number;
      embeddingTokens?: number;
      latencyMs?: number;
      error?: string;
    },
  ): Promise<void> {
    await this.prisma.agentRun.create({
      data: {
        workspaceId,
        agentId,
        kind: "PLAYGROUND",
        status,
        reason,
        tokensIn: numbers.tokensIn ?? 0,
        tokensOut: numbers.tokensOut ?? 0,
        embeddingTokens: numbers.embeddingTokens ?? 0,
        latencyMs: numbers.latencyMs ?? null,
        error: numbers.error ?? null,
      },
    });
  }

  /** `MediaStorage` is injected by the module; this keeps the call site short. */
  private storageRemove(paths: string[]): Promise<void> {
    return this.media.remove(paths);
  }

  private toHttp(error: unknown): never {
    if (error instanceof AiError) {
      const body = { code: error.code, message: error.message };

      if (error.code === "AI_NOT_CONFIGURED" || error.code === "AI_UNAUTHORIZED") {
        throw new ServiceUnavailableException(body);
      }

      if (error.code === "AI_RATE_LIMITED") throw new ConflictException(body);

      throw new BadGatewayException(body);
    }

    throw error;
  }
}
```

The picker filters by extension and the drag-and-drop path does not, so the server's `SOURCE_UNSUPPORTED` sentence is shown verbatim when a video is dropped. There is no client-side format allow-list: two lists that disagree is one bug the server cannot fix.

```tsx
"use client";

import * as React from "react";
import { Loader2, UploadCloud } from "lucide-react";

import { useToast } from "@/components/ui/toast";
import { cn } from "@/lib/utils";

import { ApiError, uploadSource } from "../api";
import type { Source } from "../types";

/** The same ceiling the server enforces; this copy only fails faster. */
const MAX_BYTES = 25 * 1024 * 1024;

/** What the file picker offers. A drag bypasses it and the server decides. */
const ACCEPT = [
  ".txt",
  ".md",
  ".csv",
  ".docx",
  ".xlsx",
  ".pdf",
  ".png",
  ".jpg",
  ".jpeg",
  ".webp",
  ".ogg",
  ".mp3",
  ".m4a",
  ".wav",
  ".opus",
].join(",");

/**
 * One file, up to 25 MB, indexed in the background.
 *
 * The upload itself is fast — the bytes go to Storage and a PENDING row is
 * written. Extraction, chunking and embedding happen on the runner, which is
 * why this component reports "indexing started" rather than "trained".
 */
export function UploadDropzone({
  agentId,
  onUploaded,
}: {
  agentId: string;
  onUploaded: (source: Source) => void;
}) {
  const toast = useToast();
  const input = React.useRef<HTMLInputElement>(null);
  const [busy, setBusy] = React.useState(false);
  const [dragging, setDragging] = React.useState(false);

  async function send(file: File) {
    if (busy) return;

    if (file.size > MAX_BYTES) {
      toast.push({
        title: "Too large",
        description: `${file.name} is ${(file.size / 1024 / 1024).toFixed(1)} MB. The limit is 25 MB.`,
        tone: "error",
      });
      return;
    }

    setBusy(true);

    try {
      const { source } = await uploadSource(agentId, file);
      onUploaded(source);
      toast.push({
        title: "Indexing started",
        description: `${source.title} is being read now.`,
        tone: "success",
      });
    } catch (caught) {
      toast.push({
        title: "Could not add the file",
        description:
          caught instanceof ApiError
            ? caught.message
            : "The file could not be uploaded.",
        tone: "error",
      });
    } finally {
      setBusy(false);

      // Cleared so choosing the same file again still fires a change.
      if (input.current) input.current.value = "";
    }
  }

  return (
    <div
      className={cn(
        "rounded-xl border border-dashed px-4 py-6 text-center transition-colors",
        dragging
          ? "border-brand bg-brand-soft"
          : "border-border bg-card/60 hover:border-brand/40",
        busy && "opacity-70",
      )}
      onDragLeave={() => setDragging(false)}
      onDragOver={(event) => {
        event.preventDefault();
        setDragging(true);
      }}
      onDrop={(event) => {
        event.preventDefault();
        setDragging(false);

        const file = event.dataTransfer.files[0];
        if (file) void send(file);
      }}
    >
      <input
        accept={ACCEPT}
        className="sr-only"
        disabled={busy}
        onChange={(event) => {
          const file = event.target.files?.[0];
          if (file) void send(file);
        }}
        ref={input}
        type="file"
      />

      <button
        className="mx-auto flex flex-col items-center gap-2 text-center focus-visible:ring-[3px] focus-visible:ring-ring/30 focus-visible:outline-none"
        disabled={busy}
        onClick={() => input.current?.click()}
        type="button"
      >
        <span className="grid size-10 place-items-center rounded-xl bg-brand-soft text-brand">
          {busy ? (
            <Loader2 className="size-5 animate-spin" />
          ) : (
            <UploadCloud className="size-5" aria-hidden="true" />
          )}
        </span>
        <span className="text-[13px] font-medium text-foreground">
          {busy ? "Uploading…" : "Drop a file, or choose one"}
        </span>
        <span className="max-w-md text-[11.5px] leading-relaxed text-muted-foreground">
          PDF, Word, Excel, CSV, text, images and voice notes up to 25 MB. Text
          is read from the file; an image is described; audio is transcribed.
        </span>
      </button>
    </div>
  );
}
```

```tsx
function sizeOf(bytes: number | null): string {
  if (!bytes) return "";
  if (bytes < 1024) return `${bytes} B`;
  if (bytes < 1024 * 1024) return `${(bytes / 1024).toFixed(0)} KB`;
  return `${(bytes / 1024 / 1024).toFixed(1)} MB`;
}

/**
 * One row per source. The status word is the state; the failure reason sits
 * under it, because "Failed" alone tells nobody what to do next.
 */
export function SourceList({
  agentId,
  sources,
  onChanged,
}: {
  agentId: string;
  sources: Source[];
  onChanged: () => void;
}) {
  const toast = useToast();
  const [armed, setArmed] = React.useState<string | null>(null);
  const [busy, setBusy] = React.useState<string | null>(null);

  async function remove(source: Source) {
    setBusy(source.id);

    try {
      await deleteSource(agentId, source.id);
      setArmed(null);
      onChanged();
      toast.push({
        title: "Source removed",
        description: `${source.title} and everything indexed from it are gone.`,
        tone: "success",
      });
    } catch (caught) {
      toast.push({
        title: "Could not remove the source",
        description:
          caught instanceof ApiError ? caught.message : "The source stayed.",
        tone: "error",
      });
    } finally {
      setBusy(null);
    }
  }

  async function retry(source: Source) {
    setBusy(source.id);

    try {
      await retrySource(agentId, source.id);
      onChanged();
      toast.push({
        title: "Queued again",
        description: `${source.title} will be read on the next pass.`,
        tone: "success",
      });
    } catch (caught) {
      toast.push({
        title: "Could not queue the source",
        description:
          caught instanceof ApiError ? caught.message : "Nothing changed.",
        tone: "error",
      });
    } finally {
      setBusy(null);
    }
  }

  if (sources.length === 0) {
    return (
      <p className="rounded-lg border border-dashed border-border bg-card/60 px-3 py-4 text-[12.5px] leading-relaxed text-muted-foreground">
        No material yet. Add a price list, a policy or a voice note above — an
        agent cannot be activated until one source is ready.
      </p>
    );
  }

  return (
    <ul className="divide-y divide-border rounded-xl border border-border bg-card">
      {sources.map((source) => {
        const style = STATUS[source.status];
        const Icon = source.kind === "TEXT" ? FileText : ImageIcon;
        const working = busy === source.id;
        const pending = source.status === "PENDING" || source.status === "PROCESSING";

        return (
          <li className="flex items-start gap-3 px-3.5 py-3" key={source.id}>
            <span className="mt-0.5 grid size-8 shrink-0 place-items-center rounded-lg bg-secondary text-muted-foreground">
              <Icon className="size-4" aria-hidden="true" />
            </span>

            <div className="min-w-0 flex-1">
              <div className="flex flex-wrap items-center gap-2">
                <p className="truncate text-[13px] font-medium text-foreground">
                  {source.title}
                </p>
                <span
                  className={cn(
                    "inline-flex rounded-full border px-2 py-0.5 text-[11px] font-medium",
                    style.className,
                  )}
                >
                  {style.label}
                </span>
              </div>

              <p className="mt-0.5 text-[11.5px] tabular-nums text-muted-foreground">
                {[
                  sizeOf(source.size),
                  source.charCount ? `${source.charCount.toLocaleString()} chars` : "",
                  source.chunkCount ? `${source.chunkCount} chunks` : "",
                  source.status === "READY" ? "searchable" : "",
                ]

                </button>
              )}
            </div>
          </li>
        );
      })}
```

- [ ] **Step 3: Write `training-panel.tsx`**

The panel polls only while something is queued or being read, and re-arms its timer when the list arrives — which is one timeout per fetch, not a `setInterval` that outlives the work. A status change is reported upward so the header's ready count follows without the parent polling too.

```tsx

import { Loader2, Plus } from "lucide-react";

import { Button } from "@/components/ui/button";
import { Label } from "@/components/ui/label";
import { useToast } from "@/components/ui/toast";
import { cn } from "@/lib/utils";

import type { Agent, Source } from "../types";

  "w-full rounded-lg border border-input bg-background px-3 text-[13.5px] text-foreground shadow-xs outline-none transition-shadow placeholder:text-muted-foreground/70 focus-visible:border-ring focus-visible:ring-ring/30 focus-visible:ring-[3px]";

/** Long enough for a paragraph of prices, short enough to stay a note. */
const MAX_NOTE = 40_000;

/**
 * The Training tab: what the agent has read, and how to add more.
 *
 * "Training" is indexing — nothing here submits a fine-tune. A source moves
 * PENDING → PROCESSING → READY on the server's runner, so the list refreshes
 * itself until nothing is in flight and then stops.

export function TrainingPanel({
  agent,
  onSourcesChanged,
}: {
  agent: Agent;
  onSourcesChanged: () => void;
}) {
  const toast = useToast();

  const [sources, setSources] = React.useState<Source[] | null>(null);
  const [error, setError] = React.useState<string | null>(null);
  const [attempt, setAttempt] = React.useState(0);
  const [title, setTitle] = React.useState("");
  const [body, setBody] = React.useState("");
  const [saving, setSaving] = React.useState(false);

  const signature = React.useRef("");
  const report = React.useRef(onSourcesChanged);
  report.current = onSourcesChanged;

  React.useEffect(() => {
    let active = true;

    fetchSources(agent.id)
      .then((next) => {
        if (!active) return;

        setSources(next.sources);
        setError(null);

        const now = next.sources.map((row) => `${row.id}:${row.status}`).join(",");

        // A row finishing changes the ready count in the header, so tell the
        // parent only when a status actually moved.
        if (signature.current !== "" && signature.current !== now) {
          report.current();
        }

        signature.current = now;
      })
      .catch((caught: unknown) => {
        if (!active) return;
        setError(
          caught instanceof ApiError
            ? caught.message
            : "The training material could not be read.",
        );
      });

    return () => {
      active = false;
    };
  }, [agent.id, attempt]);

  const working =
    sources?.some(
      (row) => row.status === "PENDING" || row.status === "PROCESSING",
    ) ?? false;

  React.useEffect(() => {
    if (!working) return;

    const timer = window.setTimeout(() => setAttempt((count) => count + 1), 3_000);

    return () => window.clearTimeout(timer);

  async function addNote() {
    if (saving) return;

    const trimmedTitle = title.trim();
    const trimmedBody = body.trim();

    if (!trimmedTitle || !trimmedBody) {
      toast.push({
        title: "A note needs a title and text",
        description: "Both fields are required, the same as a file has a name.",
        tone: "error",
      });
      return;

    setSaving(true);

    try {
      const { source } = await addTextSource(agent.id, {
        title: trimmedTitle,
        body: trimmedBody,
      });

      setSources((current) => (current ? [source, ...current] : [source]));
      setTitle("");
      setBody("");
      onSourcesChanged();
      toast.push({
        title: "Note added",
        description: "It is being indexed now.",
        tone: "success",
      });
    } catch (caught) {
      toast.push({
        title: "Could not add the note",
        description:
          caught instanceof ApiError ? caught.message : "Nothing was saved.",
        tone: "error",
      });
    } finally {
      setSaving(false);
    }
  }

  return (
    <div className="space-y-5">
      <UploadDropzone
        agentId={agent.id}
        onUploaded={(source) => {
          setSources((current) => (current ? [source, ...current] : [source]));
          onSourcesChanged();
        }}
      />

      <section className="rounded-xl border border-border bg-card p-4">
        <div className="flex items-end justify-between gap-3">
          <Label htmlFor="note-title">Or type it</Label>
          <span className="text-[11.5px] tabular-nums text-muted-foreground">
            {body.length.toLocaleString()} / {MAX_NOTE.toLocaleString()}
          </span>
        </div>

        <input
          className={cn(FIELD, "mt-1.5 h-10")}
          disabled={saving}
          id="note-title"
          maxLength={120}
          onChange={(event) => setTitle(event.target.value)}
          placeholder="Price list — retail"
          spellCheck={false}
          value={title}
        />

        <textarea
          className={cn(FIELD, "mt-2 min-h-[120px] resize-y py-2.5 leading-relaxed")}
          disabled={saving}
          id="note-body"
          maxLength={MAX_NOTE}
          onChange={(event) => setBody(event.target.value)}
          placeholder={
            "Half kg ₹249; one kg ₹449. Delivery in Pune in 24 hours, elsewhere 2–3 days. Cash on delivery available under ₹2,000."
          }
          spellCheck={false}
          value={body}
        />

        <div className="mt-2 flex items-center justify-between gap-3">
          <p className="text-[11.5px] leading-relaxed text-muted-foreground">
            A note is indexed exactly like a file, and edited by deleting it and
            writing a new one.
          </p>
          <Button
            disabled={saving || !title.trim() || !body.trim()}
            onClick={() => void addNote()}
            size="sm"
            type="button"
            variant="outline"
          >
            {saving ? <Loader2 className="animate-spin" /> : <Plus />}
            Add note
          </Button>
        </div>
      </section>

      {error ? (
        <p
          className="rounded-lg border border-destructive/35 bg-destructive/5 px-3 py-2 text-[12.5px] leading-relaxed text-foreground"
          role="alert"
        >
          {error}
        </p>
      ) : null}

      <div>
        <div className="mb-2 flex items-center justify-between">
          <h3 className="text-[13px] font-semibold text-foreground">
            Training material
          </h3>
          <p className="text-[11.5px] tabular-nums text-muted-foreground">

          </div>
```

- [ ] **Step 1: Write `ai-view.tsx`**

Three behaviours worth knowing before reading the code. The selected agent is chosen inside the state updater, so the list effect does not depend on it and cannot loop. The activation switch is the only place an agent is turned on or off, and it is disabled until a source is `READY` — the server still refuses, but the screen should not offer a click that 409s. `AgentForm` is remounted with `key={agent.id}`, which is how its initial state follows the selection without an effect.

```tsx
  activateAgent,
  ApiError,

  const toast = useToast();

  const [agents, setAgents] = React.useState<Agent[] | null>(null);

  const [busy, setBusy] = React.useState(false);

        // this update is replacing, so the list can pick a default without
        // depending on the selection and re-fetching on every switch.

          caught instanceof ApiError
            ? caught.message
            : "This agent could not be read.",
        );
      });

      active = false;

        ? await activateAgent(agent.id)
        : await deactivateAgent(agent.id);

      setAgent(result.agent);
      reload();

      toast.push({
        title: next ? "Answering automatically" : "No longer answering",
        description: next
          ? "A new message on this number gets a reply from the material."
          : "The material stays indexed. Turn it back on whenever you like.",
        tone: "success",
      });
    } catch (caught) {
      toast.push({
        title: "Could not change the switch",
        description:
          caught instanceof ApiError
            ? caught.message
            : "The agent did not change.",
        tone: "error",
      });
    } finally {
      setBusy(false);
    }
  }

  const shown = agent && agent.id === selectedId ? agent : null;
  const untrained = (shown?.readySourceCount ?? 0) === 0;

    <form
      className="flex flex-wrap items-center justify-center gap-2"
      onSubmit={(event) => {
        event.preventDefault();
        void create();
      }}
    >
```

- [ ] **Step 1: Write `reply.intake.ts`**

One query to find the active agent, one `createMany` for the whole delivery. `skipDuplicates` plus the unique `inboundMessageId` is the second guard behind the store's own `wamid` dedupe: two independent reasons a retried delivery can never produce a second reply.

```ts
import { Injectable } from "@nestjs/common";
import type { MessageKind } from "@prisma/client";

import type { StoredInbound } from "../inbox/inbox.store";
import { PrismaService } from "../prisma/prisma.service";

/**
 * What the model can be asked about. A photo, a document or a location is not
 * a question by itself, and a reaction is explicitly not one — the inbox
 * already refuses to count it as unread for the same reason.
 */
const ANSWERABLE = new Set<MessageKind>(["TEXT", "BUTTON", "INTERACTIVE"]);

/**
 * Turns a signed delivery into AI work.
 *
 * Nothing is answered here: this writes QUEUED rows and returns. `AgentsRunner`
 * claims them, so the two-second model call never happens on Meta's request —
 * a slow webhook is a webhook Meta retries.
 */
@Injectable()
export class ReplyIntake {
  constructor(private readonly prisma: PrismaService) {}

  async enqueue(
    account: { id: string; workspaceId: string },
    stored: StoredInbound[],
  ): Promise<number> {
    if (stored.length === 0) return 0;

    const answerable = stored.filter(
      (row) => ANSWERABLE.has(row.kind) && (row.body ?? "").trim().length > 0,
    );

    if (answerable.length === 0) return 0;

    const agent = await this.prisma.agent.findFirst({
      where: { whatsappAccountId: account.id, isActive: true },
      select: { id: true },
    });

    // Without an active agent the message is still stored and still visible in
    // the Inbox. There is simply nobody to answer it.
    if (!agent) return 0;

    const created = await this.prisma.agentRun.createMany({
      data: answerable.map((row) => ({
        workspaceId: account.workspaceId,
        agentId: agent.id,
        kind: "REPLY" as const,
        conversationId: row.conversationId,
        inboundMessageId: row.messageId,
        status: "QUEUED" as const,
      })),
      skipDuplicates: true,
    });

    return created.count;
  }
}
```

The gates run before the model call and in cheapest-first order. `answer` never throws: a runner that has to defend itself against one bad run ends up with two error paths, and the run row is the record either way.

```ts

import type { Agent } from "@prisma/client";

import { InboxSender, type SendTarget } from "../inbox/inbox.sender";
import { windowOpen } from "../inbox/inbox.view";
import { PrismaService } from "../prisma/prisma.service";
import { AiError } from "./ai.errors";
import { OpenAiProvider } from "./ai.openai";
import {
  HANDOFF_MESSAGE,
  cleanReply,
  matchesEscalation,
  messagesOf,
  systemPrompt,
  type Turn,
} from "./reply.prompt";
import { RetrievalService } from "./retrieval.service";

/** A candidate a stuck process left behind is resumed, not lost. */
const STALE_MS = 90_000;

/** After this many interruptions the run is left FAILED rather than looped. */
const MAX_ATTEMPTS = 2;

/** The last few turns give the model the thread; older ones only cost tokens. */
const HISTORY_TURNS = 10;

/** One WhatsApp-sized answer. Not a setting: a longer one is not a reply. */
const MAX_TOKENS = 400;

export interface ClaimedRun {
  id: string;
  workspaceId: string;
  agentId: string;
  conversationId: string | null;
  inboundMessageId: string | null;
}

/**
 * Turns one queued run into one WhatsApp message, or into a recorded reason
 * why there is none.
 *
 * Every exit writes a terminal status, so the Activity tab can always say what
 * happened: `SENT`, or `SKIPPED` with `paused`, `superseded`, `window-closed`,
 * `no-agent`, `no-context` or `handoff`, or `FAILED` with the vendor's sentence.
 */
@Injectable()
export class ReplyService {
  constructor(
    private readonly prisma: PrismaService,
    private readonly sender: InboxSender,
    private readonly retrieval: RetrievalService,
    private readonly provider: OpenAiProvider,
  ) {}

  /**
   * One row at a time, atomically. `SKIP LOCKED` is what lets two ticks — or
   * two processes sharing the pooler — never claim the same run.
   */
  async claim(): Promise<ClaimedRun | null> {
    const rows = await this.prisma.$queryRaw<ClaimedRun[]>`
      UPDATE agent_runs
         SET status = 'CLAIMED', claimed_at = now()
       WHERE id = (
         SELECT id
           FROM agent_runs
          WHERE status = 'QUEUED'
          ORDER BY created_at
          LIMIT 1
          FOR UPDATE SKIP LOCKED
       )
      RETURNING id,
                workspace_id        AS "workspaceId",
                agent_id            AS "agentId",
                conversation_id     AS "conversationId",
                inbound_message_id  AS "inboundMessageId"
    `;

    return rows[0] ?? null;
  }

  /** A claim older than the timeout means the process died mid-call. */
  async releaseStale(): Promise<number> {
    const stale = await this.prisma.agentRun.findMany({
      where: {
        status: "CLAIMED",
        claimedAt: { lt: new Date(Date.now() - STALE_MS) },
      },
      select: { id: true, attempts: true },
    });

    for (const row of stale) {
      await this.prisma.agentRun.update({
        where: { id: row.id },
        data:
          row.attempts >= MAX_ATTEMPTS
            ? {
                status: "FAILED",
                error: "The reply was interrupted twice and will not be retried.",
              }
            : { status: "QUEUED", claimedAt: null, attempts: { increment: 1 } },
      });
    }

    return stale.length;
  }

  /** Never throws: the runner's only job is to keep ticking. */
  async answer(run: ClaimedRun): Promise<void> {
    const started = Date.now();

    const row = await this.prisma.agentRun.findUnique({
      where: { id: run.id },
      include: { agent: true },
    });

    if (!row?.conversationId) {
      await this.skip(run.id, "no-agent");
      return;
    }

    const conversation = await this.prisma.conversation.findUnique({
      where: { id: row.conversationId },
      select: {
        id: true,
        workspaceId: true,
        aiPausedAt: true,
        lastInboundAt: true,
        contact: { select: { waId: true } },
        account: {
          select: {
            phoneNumberId: true,
            graphVersion: true,
            accessTokenCipher: true,
          },
        },
      },
    });

    if (!conversation) {
      await this.skip(run.id, "no-agent");
      return;
    }

    const target: SendTarget = {
      workspaceId: conversation.workspaceId,
      conversationId: conversation.id,
      waId: conversation.contact.waId,
      account: conversation.account,
    };

    const agent: Agent = row.agent;

    // Cheapest first: three of these are one column and a comparison.
    if (!agent.isActive) {
      await this.skip(run.id, "no-agent");
      return;
    }

    if (conversation.aiPausedAt) {
      await this.skip(run.id, "paused");
      return;
    }

    const newer = await this.prisma.agentRun.count({
      where: {
        conversationId: conversation.id,
        status: "QUEUED",
        createdAt: { gt: row.createdAt },
      },
    });

    // A burst of three messages is one answer, for the third.
    if (newer > 0) {
      await this.skip(run.id, "superseded");
      return;
    }

    if (!windowOpen(conversation.lastInboundAt)) {
      await this.skip(run.id, "window-closed");
      return;
    }

    const inbound = row.inboundMessageId
      ? await this.prisma.message.findUnique({
          where: { id: row.inboundMessageId },
          select: { body: true },
        })
      : null;

    const question = (inbound?.body ?? "").trim();

    if (!question) {
      await this.skip(run.id, "no-context");
      return;
    }

    // Before the model: a complaint must never depend on what a model decides
    // to say about it.
    if (matchesEscalation(question, agent.escalateKeywords)) {
      await this.handoff(run.id, conversation.id, target, agent.id, "handoff");
      return;
    }

    try {
      // Cosmetic and already failure-tolerant; it must never stop a reply.
      await this.sender.typing(target);
    } catch {
      // ignore
    }

    try {
      const { chunks, embedTokens } = await this.retrieval.search(
        agent.id,
        question,
      );

      if (chunks.length === 0) {
        await this.handoff(run.id, conversation.id, target, agent.id, "no-context");
        return;
      }

      const business = await this.prisma.businessProfile.findUnique({
        where: { workspaceId: conversation.workspaceId },
        select: { companyName: true },
      });

      const answer = await this.provider.chat({
        model: agent.model,
        system: systemPrompt({
          systemPrompt: agent.systemPrompt,
          companyName: business?.companyName ?? null,
          chunks,
          maxReplyChars: agent.maxReplyChars,
        }),
        messages: messagesOf(await this.historyOf(conversation.id)),
        temperature: agent.temperature,
        maxTokens: MAX_TOKENS,
      });

      const body = cleanReply(answer.text, {
        maxChars: agent.maxReplyChars,
        context: chunks.map((chunk) => chunk.text).join("\n\n"),
      });

      if (!body) {
        await this.handoff(run.id, conversation.id, target, agent.id, "no-context");
        return;
      }

      const sent = await this.sender.text({
        ...target,
        body,
        quote: null,
        agentId: agent.id,
      });

      await this.prisma.agentRun.update({
        where: { id: run.id },
        data: {
          status: "SENT",
          outboundMessageId: sent.id,
          tokensIn: answer.tokensIn,
          tokensOut: answer.tokensOut,
          embeddingTokens: embedTokens,
          latencyMs: Date.now() - started,
          reason: null,
          error: null,
        },
      });
    } catch (error) {
      // The window can close between the gate and the send.
      if (error instanceof ConflictException) {
        await this.skip(run.id, "window-closed");
        return;
      }

      // A revoked key is a configuration fact, not a transient failure:
      // continuing to try spends money to learn nothing new.
      if (error instanceof AiError && error.code === "AI_UNAUTHORIZED") {
        await this.prisma.agent
          .update({ where: { id: agent.id }, data: { isActive: false } })
          .catch(() => undefined);
      }

      await this.prisma.agentRun.update({
        where: { id: run.id },
        data: {
          status: "FAILED",
          error: sentenceOf(error),
          latencyMs: Date.now() - started,
        },
      });
    }
  }

  /** The last few text turns, oldest first, with the customer as `user`. */
  private async historyOf(conversationId: string): Promise<Turn[]> {
    const rows = await this.prisma.message.findMany({
      where: { conversationId, kind: "TEXT", body: { not: null } },
      orderBy: { createdAt: "desc" },
      take: HISTORY_TURNS,
      select: { direction: true, body: true },
    });

    return rows
      .reverse()
      .map((row) => ({
        role: row.direction === "INBOUND" ? ("user" as const) : ("assistant" as const),
        body: row.body ?? "",
      }));
  }

  /**
   * One fixed line, then the thread is paused. A handoff is a success for the
   * customer even though the run is `SKIPPED`: nobody was answered wrongly.
   */
  private async handoff(
    runId: string,
    conversationId: string,
    target: SendTarget,
    agentId: string,
    reason: string,
  ): Promise<void> {
    await this.pause(conversationId, reason);

    try {
      const sent = await this.sender.text({
        ...target,
        body: HANDOFF_MESSAGE,
        quote: null,
        agentId,
      });

      await this.prisma.agentRun.update({
        where: { id: runId },
        data: {
          status: "SKIPPED",
          reason,
          outboundMessageId: sent.id,
          error: null,
        },
      });
    } catch (error) {
      // The reason still stands — a person has to answer — but the customer
      // never received the line, which is worth recording.
      await this.prisma.agentRun.update({
        where: { id: runId },
        data: { status: "SKIPPED", reason, error: sentenceOf(error) },
      });
    }
  }

  private async pause(conversationId: string, reason: string): Promise<void> {
    await this.prisma.conversation.update({
      where: { id: conversationId },
      data: { aiPausedAt: new Date(), aiPauseReason: reason },
    });
  }

  private async skip(runId: string, reason: string): Promise<void> {
    await this.prisma.agentRun.update({
      where: { id: runId },
      data: { status: "SKIPPED", reason },
    });
  }
}

function sentenceOf(error: unknown): string {
  if (error instanceof HttpException) return error.message;
  return error instanceof Error ? error.message : "The reply failed.";
}
```

- [ ] **Step 1: Write the runner**

It mirrors `CampaignsRunner` exactly: an `unref`'d interval, a `busy` flag so a slow model call cannot stack ticks, and a `catch` so one bad row never kills the loop. It differs in one way — it takes both kinds of work in the same tick, because a bulk upload must not delay a customer's reply by ten seconds.

```ts
import {
  Injectable,
  Logger,
  type OnModuleDestroy,
  type OnModuleInit,
} from "@nestjs/common";

import { KnowledgeService } from "./knowledge.service";
import { ReplyService } from "./reply.service";

/**
 * One second, because a reply is a person waiting. Indexing is fast enough at
 * this rate for a handful of uploads, and both kinds of work are claimed
 * atomically, so a second process would only add throughput.
 */
const TICK_MS = 1_000;

/**
 * The process's own work loop: index one source, then answer one run.
 *
 * No queue, no Redis, no worker dyno. The rows are the queue — `PENDING`
 * sources and `QUEUED` runs — and this loop only decides who takes them, which
 * is why the whole thing survives a restart without any bookkeeping.
 */
@Injectable()
export class AgentsRunner implements OnModuleInit, OnModuleDestroy {
  private readonly logger = new Logger(AgentsRunner.name);
  private timer: ReturnType<typeof setInterval> | null = null;
  private busy = false;

  constructor(
    private readonly knowledge: KnowledgeService,
    private readonly replies: ReplyService,
  ) {}

  onModuleInit(): void {
    this.timer = setInterval(() => void this.tick(), TICK_MS);

    // A background loop must never be the reason the process stays alive.
    this.timer.unref();
  }

  onModuleDestroy(): void {
    if (this.timer) clearInterval(this.timer);
    this.timer = null;
  }

  private async tick(): Promise<void> {
    if (this.busy) return;
    this.busy = true;

    try {
      // Both recoveries are two-column updates and are what makes a crash
      // mid-call resume instead of leaving a row stuck forever.
      await this.knowledge.recoverStale();
      await this.replies.releaseStale();

      const source = await this.knowledge.claim();
      if (source) await this.knowledge.index(source);

      const run = await this.replies.claim();
      if (run) await this.replies.answer(run);
    } catch (error) {
      // One bad row must not stop the loop: the row already holds its own
      // failure, and the next tick takes the next one.
      this.logger.error(
        `Agent pass failed: ${
          error instanceof Error ? error.message : "unknown failure"
        }`,
      );
    } finally {
      this.busy = false;
    }
  }
}
```

```ts
import {
  Controller,
  HttpCode,
  Param,
  ParseUUIDPipe,
  Post,
  UseGuards,
} from "@nestjs/common";

import type { AuthClaims } from "../auth/auth.types";
import { CurrentUser } from "../auth/current-user.decorator";
import { SupabaseAuthGuard } from "../auth/supabase-auth.guard";
import { AgentsService } from "./agents.service";

/**
 * AI state for one conversation.
 *
 * A path that names a conversation and a module that owns the agent: the URL
 * follows the resource, the code follows the dependency. The inbox never
 * imports this module, so there is no cycle to break.
 */
@Controller("v1/inbox/conversations/:id/ai")
@UseGuards(SupabaseAuthGuard)
export class AiController {
  constructor(private readonly agents: AgentsService) {}

  /** POST .../ai/pause — what a person does when they take the thread over. */
  @Post("pause")
  @HttpCode(200)
  pause(
    @CurrentUser() claims: AuthClaims,
    @Param("id", ParseUUIDPipe) id: string,
  ) {
    return this.agents.pauseConversation(claims, id, "manual");
  }

  /** POST .../ai/resume — clears the pause; the agent answers again. */
  @Post("resume")
  @HttpCode(200)
  resume(
    @CurrentUser() claims: AuthClaims,
    @Param("id", ParseUUIDPipe) id: string,
  ) {
    return this.agents.resumeConversation(claims, id);
  }
}
```

```tsx
 */
function pauseReason(reason: string | null): string {
  switch (reason) {
    case "human":
      return "A teammate replied here, so the agent stepped back.";
    case "manual":
      return "Turned off from this thread.";
    case "handoff":
      return "The agent asked for a person on this thread.";
    case "no-context":
      return "The material had no answer, so the agent asked for a person.";
    default:
      return "The agent is not answering this thread.";
  }
}
```

```tsx
function Figure({ label, value }: { label: string; value: string }) {
  return (
    <div className="bg-card px-4 py-3">
      <p className="text-[11px] text-muted-foreground">{label}</p>
      <p className="mt-0.5 text-[15px] font-semibold tabular-nums text-foreground">

      </p>

/** `12 Nov, 14:32` — the browser's locale, after a client fetch. */
function when(iso: string): string {
  return new Date(iso).toLocaleString(undefined, {
    day: "numeric",
    month: "short",
    hour: "2-digit",
    minute: "2-digit",
  });
}

/** In, out and embedded in one figure; the split is the tooltip. */
function tokens(run: Run): string {
  const total = run.tokensIn + run.tokensOut + run.embeddingTokens;

  return total === 0 ? "—" : total.toLocaleString();
}

function latency(ms: number | null): string {
  if (ms === null) return "—";
  if (ms < 1_000) return `${ms} ms`;

  return `${(ms / 1_000).toFixed(1)} s`;
}
```

### If something fails

| Symptom | Likely cause | Where to look |
| --- | --- | --- |
| Runs stay `QUEUED` and no reply ever comes | `AgentsRunner` was never provided, or `AgentsModule` is missing from `AppModule` | the boot log; Nest logs every instantiated provider |
| Every run is `SKIPPED` with `no-agent` | no active agent, or the agent is bound to a different `whatsappAccountId` | `select id, is_active, whatsapp_account_id from agents;` |
| Every run is `SKIPPED` with `superseded` | a burst of messages; only the newest is answered | expected — the customer gets one reply, not five |
| Every source ends `FAILED` | `OPENAI_API_KEY` missing or wrong, or the bucket did not accept the upload | the source row's `error` column holds the sentence |
| Playground answers `no-context` for a question the PDF answers | the PDF is a scan, or its chunks are `PENDING` | the source row's `status`, `chunk_count`, `error` |
| The reply is sent but the inbox shows no `AI` badge | `InboxSender.text` was called without `agentId` | `select id, agent_id from messages order by created_at desc limit 5;` |
| Two replies to one message | intake is invoked twice, or the unique index on `inbound_message_id` is missing | `select indexname from pg_indexes where tablename = 'agent_runs';` |
| `P1001` or `P1013` at boot | the pooler string | `npm run check:db` in `Backend` |
